# 카드 공유 후속 개선 검증 — 2026-10-29

이 문서는 배포 전 로컬 소스와 iOS 시뮬레이터 검증 기록입니다. **후속으로 TestFlight 1.1.1(37)에 반영했습니다.** [배포 기록](../1.1.1/TESTFLIGHT-build37.md)을 참고하세요. 기존 1.1.1(35)에는 포함되지 않습니다. 아래 검증 이후 빌드 37에서 Apple 요구 사진 보관함 목적 설명을 추가했습니다.

## 변경

- 저장된 여행 ID가 있으면 우측 상단에 `수정`, 신규·자동 초안에는 `저장`을 표시합니다.
- 미리보기 페이지와 관계없이 전체 카드를 순서대로 PNG로 만들고 한 번의 공유창에 함께 전달합니다. 일부 페이지 생성이 실패하면 공유를 시작하지 않습니다.
- 카드 날짜 아래에 `출발 시각`, `도착 시각(설정)`을 구분합니다. 도착 설정값은 사용자가 정한 마감 기준입니다.
- 설정의 카드 이미지 타이틀에서 닉네임을 저장합니다. 빈값은 `tribble`로 표시하며 여행·SNS 프로필과 별도 저장합니다.
- `expo-sharing`을 `react-native-share` 12.3.1로 교체했습니다. iOS에는 사진 추가 전용 안내를, Android에는 앱 내부·외부 캐시 파일을 공유할 FileProvider 경로를 구성했습니다. 새 네이티브 빌드가 필요합니다.

## iOS 네이티브 확인

- Xcode 26.2, iOS 26.2 iPhone 16e 시뮬레이터, Debug arm64 빌드 성공.
- 예시 저장 여행에서 상단 `수정` 버튼 확인.
- 설정에서 `느긋한 여행자`를 입력·저장하고 별도 기기 저장소 반영 및 카드 표시 확인.
- 5개 장소 피드 카드 2장: [첫 페이지](proof/feed-1.png), [두 번째 페이지](proof/feed-2.png). 각 1080×1350 PNG이며 장소 1–3 / 4–5가 누락 없이 이어집니다.
- iOS 공유창에서 [Save 2 Images](proof/save-two-images.png)를 선택해 사진 추가 권한을 허용한 뒤 두 장을 실제 시뮬레이터 사진 보관함에 저장했습니다. 두 파일의 SHA-256이 생성 원본과 각각 일치합니다. [검증 결과](photos-verification.json).
- [스토리 PNG](proof/story.png) 1080×1920에 5개 장소·닉네임·시간 라벨·푸터가 잘림 없이 표시됩니다.
- 공유 취소와 사진 저장 후 미리보기 버튼이 다시 활성화되고 iOS 임시 PNG가 정리됩니다.

기존 SNS 프로필·여행 데이터는 수정하지 않았습니다. 시뮬레이터 테스트는 합성 여행을 사용했고 앱 저장소는 이전 상태로 복원했습니다. 실제 기기의 각 SNS 앱이 여러 장을 수신·게시하는 동작과 Android 네이티브 실행은 이번에 검증하지 않았습니다. 공개 지원·개인정보 문서와 스토어 문구도 아직 게시하지 않았습니다.
