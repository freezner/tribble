# 일정 헤더의 카드 생성 버튼 강조

2026-10-29 검증, 2026-10-30 배포 기록 갱신. 이 변경은 TestFlight 1.1.1(39)에 포함됐으며 Apple 처리와 기존 내부 테스트 그룹 연결을 완료했습니다. 정식 심사 진행 상태는 [배포 기록](../1.1.1/store-20261030-submission.json)을 참고합니다.

- 우측 상단의 공유 아이콘을 사진 아이콘과 ‘카드 생성’ 문구가 있는 브랜드색 버튼으로 바꾸고 맨 오른쪽에 배치했습니다.
- 저장/수정은 옅은 배경과 테두리를 사용하는 보조 버튼으로 바꿨습니다. 헤더 저장 글자·로딩 표시 스타일을 분리하여 시간 설정의 적용 버튼은 기존 대비를 유지합니다.
- 두 버튼은 최소 44pt 터치 높이를 사용합니다. 비활성 상태와 저장 중 상태를 접근성에 전달하고 한국어·영어·일본어·중국어 문구를 추가했습니다.
- 기존 저장·일정 반영·카드 생성 로직을 유지합니다. 기존 테스트의 카드 버튼 선택자만 새 접근성 이름으로 갱신했습니다.
- 관련 기존 테스트 40개(`draftUi`, `socialUi`), 타입 검사 및 diff 검사 통과.
- iPhone 16e / iOS 26.2에서 한국어 헤더가 겹치지 않고 표시되며, ‘카드 생성’을 눌러 기존 SNS 카드 미리보기와 두 장 공유 버튼이 열리는 것을 확인했습니다. 다른 언어·320pt 기기의 실제 렌더링은 이번에 별도 실행하지 않았습니다.
- 테스트용 여행 저장소는 원래대로 복구하고 전용 시뮬레이터와 Metro를 종료했습니다.
