# SNS별 여행 카드 출력 검증

검증일: 2026-10-29. 이 문서는 배포 전 작업 트리 검증 기록입니다. **후속으로 TestFlight 1.1.1(37)의 업로드·Apple 처리·내부 테스트 그룹 연결을 완료했습니다.** [배포 기록](../1.1.1/TESTFLIGHT-build37.md)을 참고하세요. 정식 스토어 배포는 수행하지 않았으며, 기존 TestFlight 1.1.1(35)에는 이번 프리셋 및 이전 전체 페이지 공유 개선이 포함되지 않습니다.

## 구현

- SNS 프로필 등록 여부와 무관하게 Instagram·X·Facebook·TikTok 선택을 제공합니다.
- Instagram·Facebook은 게시물/스토리를 선택합니다. 출력 규격에 맞춰 캔버스, 여백, 페이지당 장소 수와 실제 PNG 해상도가 함께 바뀝니다.
- SNS 또는 게시 위치를 변경하면 미리보기를 첫 장으로 돌리고 새 카드의 레이아웃 준비가 끝난 뒤 공유를 허용합니다. 같은 9:16 크기인 Instagram/Facebook 스토리 사이 전환도 새 캡처 대상으로 처리합니다.
- 이미지에 표시할 SNS 프로필은 출력 규격 선택과 독립적입니다. 닉네임·출발 시각·설정 도착 시각·전체 일정 기준 도착 시각과 장소 번호를 유지합니다.
- 모든 페이지를 한 번에 생성해 운영체제 공유창에 전달합니다. X 4장·TikTok 35장 게시 한도를 넘으면 나누어 게시하도록 안내하고, 저장할 이미지 수는 줄이지 않습니다.

공식 지원 범위와 앱이 정한 프리셋의 차이는 [규격 근거](SPECIFICATIONS.md)에 정리했습니다. 스토리와 TikTok의 여백은 앱의 가독성 설계이며 모든 SNS 화면에서 겹침이 없음을 보장하는 공식 안전 영역은 아닙니다.

- `npm run typecheck`: 통과.

- 한국어·영어·일본어·중국어 SNS 번역 키 52개 일치.
- 기존 `feed`/`story`와 신규 6가지 형식의 픽셀 비율·페이지 분할·전체 일정 시간·레이아웃 높이를 검증했습니다.
- iOS 2×/3× 및 Android 3× 픽셀 비율에서 명시한 출력 크기, 모든 페이지 전달, 부분 캡처 실패 시 공유 중단, 취소, 플랫폼별 임시 파일 처리를 모의 네이티브 테스트로 검증했습니다.
- UI 테스트는 프로필 없는 상태의 모든 SNS 선택, 게시 위치 전환, 미리보기 페이지 초기화, 준비 중 공유 차단, 모든 페이지 공유와 X 게시 한도 경계를 포함합니다.

## iOS 실제 PNG

iPhone 16e / iOS 26.2 시뮬레이터에서 실행했습니다. 앞선 카드 개선 때 빌드한 `react-native-share` 포함 Debug 앱에 현재 JavaScript 번들을 연결했으며, 이번에는 네이티브 바이너리를 새로 빌드하지 않았습니다.

실제 API 요청이 없는 5개 장소·수동 이동 시간 테스트 일정과 닉네임 `느긋한 여행자`를 사용했습니다. 각 프리셋을 UI에서 선택하고 실제 공유창을 연 상태에서 생성된 PNG를 확인했습니다.

| 프리셋 | PNG 해상도 | 생성 장수 |
| --- | --- | --- |
| Instagram 게시물 | 1080 × 1440 | 2 |
| Instagram 스토리 | 1080 × 1920 | 2 |
| Facebook 게시물 | 1440 × 1800 | 2 |
| Facebook 스토리 | 1080 × 1920 | 2 |
| X 게시물 | 1200 × 1200 | 3 |
| TikTok 사진 게시물 | 1080 × 1920 | 2 |

총 13장의 해상도·장수·SHA-256을 파일에서 확인했습니다. [파일 검증 결과](native-export-verification.json)와 [선택 화면](proof/sns-selector.png)을 보관했습니다. 대표 카드와 마지막 페이지에서 타이틀·시간·장소·페이지 표시·하단 출처가 캔버스 안에 배치되는 것을 확인했습니다. 공유창을 취소해도 오류 없이 돌아오며 iOS 임시 캡처가 정리됩니다.

사진 보관함에 두 페이지를 실제로 저장하고 원본과 SHA-256을 대조한 검증은 [앞선 전체 페이지 공유 기록](../card-improvements/VALIDATION.md)에 있습니다. 이번 검증은 새 출력 규격별 PNG 생성과 다중 이미지 전달을 확인한 것으로, 6가지 형식을 각각 사진 보관함에 다시 저장한 것은 아닙니다.
