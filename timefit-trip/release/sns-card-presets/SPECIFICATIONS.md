# SNS 여행 카드 구현 프리셋과 공식 규격 근거

확인일: 2026-10-29 (2026년 10월 공개 문서 기준)

이 기능은 선택한 SNS에 맞는 카드 이미지를 만드는 기능입니다. SNS 로그인·자동 게시·게시 계정 선택 기능이 아니며, 운영체제 공유창이나 사진 저장 후 사용자가 게시를 마무리합니다. 아래 표는 **공식 문서에서 직접 확인한 지원 범위**와 **Tribble이 정한 이미지 프리셋**을 구분합니다. 최종 게시 화면·앱 버전·여러 장 배치에 따른 잘림이나 이미지 재압축까지 보장하지 않습니다.

## 공식 문서에서 확인한 사실

### Instagram 일반 사진

[Instagram에서 공유하는 사진의 이미지 해상도](https://help.instagram.com/1631821640426723)를 공식 고객 센터의 브라우저 화면에서 직접 확인했습니다.

- 사진 업로드 최대 너비는 1080px로 안내합니다.
- 너비 320~1080px이고 비율이 1.91:1~3:4이면 원래 해상도를 유지한다고 설명합니다.
- 너비 1080px 기준으로 높이 566~1440px에 해당합니다.
- 범위를 벗어난 비율은 잘리고, 작은 사진은 확대되며 큰 사진은 너비 1080px로 축소될 수 있습니다.

따라서 1080×1440(3:4)은 현재 일반 사진 도움말에 명시된 지원 범위의 세로 끝값입니다. 이 안내를 Instagram 광고·Reels·Graph API 게시 규격이나 모든 캐러셀 미리보기의 잘림 보장으로 확대 해석하지 않습니다.

### X 일반 사진과 장수

[X 사진·GIF 게시 도움말](https://help.x.com/en/using-x/posting-gifs-and-pictures)은 **단일 사진**의 비율이 2:1~3:4이면 전체 이미지가 표시된다고 안내합니다. 이 범위에는 정사각형과 4:5도 들어갑니다. 이 문서에서 1200×1200 같은 필수 또는 권장 해상도는 확인하지 않았습니다.

같은 공식 도움말의 파일 요건에는 일반 사진 최대 5MB, GIF·JPEG·PNG 지원이 나옵니다. 별도 Media Studio의 더 큰 업로드 제한이나 광고 이미지 크기를 일반 모바일 게시물 규격으로 사용하지 않습니다.

[X 게시 방법](https://help.x.com/en/using-x/how-to-post)은 게시물당 최대 4개 미디어 항목을 안내합니다. 사진만으로 구성한 여행 카드도 한 게시물에는 최대 4장이라는 전제로 안내합니다. 여러 사진을 한 번에 붙인 경우의 타일 미리보기는 단일 사진의 전체 표시 안내와 구분합니다.

### TikTok 일반 사진, SDK와 게시 API의 차이

[TikTok 게시물 만들기](https://support.tiktok.com/en/using-tiktok/creating-videos/making-a-post)의 일반 사진 게시 안내는 사진을 최대 35장 선택할 수 있다고 설명합니다. 이 페이지에서는 일반 사진의 권장 비율·픽셀 해상도를 찾지 못했습니다.

[현행 iOS Share Kit](https://developers.tiktok.com/docs/en/share-kit-ios-quickstart-v2)는 이미지·동영상의 가로/세로 비율을 1/2.2~2.2, 이미지 장수를 최대 35장으로 안내합니다. 9:16은 이 범위 안에 있습니다. 다만 Tribble은 이 SDK를 연동하지 않으므로 이 수치를 운영체제 공유창의 수신 성공 보장으로 사용하지 않습니다.

[Content Posting API Media Transfer Guide](https://developers.tiktok.com/docs/en/content-posting-api-media-transfer-guide)의 이미지 요건은 WebP·JPEG, 최대 1080p, 이미지당 최대 20MB입니다. 이 요건은 **직접 게시 API용**이며, 사진 앱에서 고른 이미지나 운영체제 PNG 공유에 그대로 적용된다고 단정하지 않습니다. 특히 ‘1080p’라는 표현만으로 일반 사진 게시의 권장 크기를 1080×1920이라고 해석하지 않습니다.

### Facebook 및 스토리의 확인 한계

이전에 일반 사진 품질 안내로 쓰이던 [Facebook 고객 센터 주소](https://www.facebook.com/help/266520536764594)는 이번 확인에서 브라우저에도 페이지를 이용할 수 없다는 안내가 표시됐습니다. 일반 게시물의 최신 비율·권장 해상도를 확인하지 못했으므로 과거의 720/960/2048px 안내나 비공식 가이드 수치를 현재 공식 요건으로 기록하지 않습니다.

광고용 Feed/Stories 규격, 링크 미리보기의 Open Graph 이미지 규격, 프로필·커버 이미지 규격은 이번 일반 여행 카드 게시 프리셋의 공식 근거에서 제외했습니다. Facebook 1440×1800과 두 플랫폼의 스토리 1080×1920은 이 구분을 유지한 앱 선택값입니다.

## 앱 안내와 검증 범위

- 화면에는 SNS별 프리셋·비율·생성 해상도를 표시하되 ‘공식 최적’ 또는 ‘잘림 없음’을 약속하지 않습니다.
- X 4장·TikTok 35장을 넘으면 전체 이미지 생성·저장은 유지하면서 여러 게시물로 나누라는 안내를 제공합니다. 장수 제한을 피하려고 페이지를 누락하거나 순서를 바꾸지 않습니다.
- 여러 장을 공유할 때 대상 앱에서 실제 수신한 장수와 순서를 사용자가 확인하도록 안내합니다. 수신 앱에 따라 공유창의 처리 방식이 다를 수 있습니다.
- 생성 파일의 실제 PNG 해상도·비율·장수·순서와 카드 글자 잘림을 검증하고, 최종 SNS 게시 UI의 여백·재압축은 해당 앱에서 별도로 확인합니다.
- 이번 문서는 공개 규격 조사와 프리셋 설계 근거입니다. SNS 앱에 실제 게시하거나 계정·권한을 변경하지 않았으며 새 TestFlight 배포 성공을 뜻하지 않습니다.
