여행 카드 저장과 SNS별 이미지 규격을 개선한 내부 테스트 빌드입니다.

• 이미 저장한 여행을 열었을 때 우측 상단에 ‘수정’이 표시되고, 수정 후 같은 여행에 저장되는지 확인해 주세요. 새 여행은 ‘저장’으로 표시됩니다.
• 장소가 많은 여행의 카드를 공유·저장하면 모든 페이지가 한 번에 전달되는지 확인해 주세요. iOS 공유창에서 ‘이미지 저장’을 선택했을 때 사진 앱에 모든 장이 저장되어야 합니다.
• 카드 상단의 ‘출발 시각’과 ‘도착 시각(설정)’이 여행 설정과 맞는지 확인해 주세요.
• 설정의 ‘카드 이미지 타이틀’에 닉네임을 입력하고 앱 재실행 후에도 유지되는지 확인해 주세요. 입력란을 비워 저장하면 기본 tribble이 표시됩니다.
• 카드 생성 화면에서 Instagram·X·Facebook·TikTok을 선택해 미리보기 비율, 출력 해상도와 페이지 수가 바뀌는지 확인해 주세요. SNS 프로필 등록 없이도 선택할 수 있습니다.
• Instagram 게시물은 1080×1440, Facebook 게시물은 1440×1800, X는 1200×1200, Instagram·Facebook 스토리와 TikTok 사진은 1080×1920 PNG로 생성됩니다.
• SNS·게시물/스토리·페이지·표시 프로필을 빠르게 바꾼 뒤에도 선택한 카드 전체가 올바르게 공유되는지 확인해 주세요. 공유창을 취소한 후 다시 공유하는 동작도 확인해 주세요.
• 실제 SNS 앱에 이미지를 불러온 뒤 글자 잘림·선명도·여러 장의 순서를 확인해 주세요. 출력 기준 SNS와 실제 공유할 앱은 별도로 선택합니다. X 4장·TikTok 35장을 넘는 경우 모든 이미지를 저장한 뒤 나누어 게시할 수 있습니다.
• 기존 여행·초안 재개와 국내 자동차·도보 경로 계산도 확인해 주세요.
