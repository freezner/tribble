# Tribble 1.1.0 icon

The selected icon is the opaque coral artwork in `master.png`. `previous.png` preserves the replaced icon. Transparent generation experiments were rejected and are not included in the app.

Generated with the built-in image generation tool on 2026-10-26. Production files are mechanically resized from the selected master for each platform; iOS uses an opaque RGB 1024 × 1024 PNG. The source generated image is preserved outside the project as well.

## Final generation prompt

```text
Use case: logo-brand
Asset type: final iOS app icon, single square 1024x1024 flat artwork for Tribble, a calm day-trip planner that fits stops and travel into the time you have.
Primary request: redesign the existing brand into a sophisticated, distinctive app icon. Keep the warm burnt-coral and ivory identity, but make the symbol contemporary and beautifully simple.
Subject: one bold custom ivory lowercase-t monogram, drawn as an elegant continuous rounded route. The vertical stem curves smoothly into a generous upward-curving hook at the bottom, suggesting a journey; the short horizontal crossbar is simple and rounded. One small solid ivory circular waypoint sits in the open space to the lower right, balanced with the hook. The mark should be a custom geometric logo rather than a typed character. Precise smooth curves, confident proportions, optical balance, excellent readability at 40 pixels.
Composition: centered mark fills about 62% of the square; generous even breathing room. Entire canvas is opaque warm burnt coral (#AE4F3D with a very subtle warm tonal shift), ivory mark approximately #FFF9EC. Premium editorial travel brand, calm, warm, memorable, minimal. Very restrained soft depth at most, mostly flat and vector-like.
Constraints: output ONLY one finished full-bleed square icon image, not a mockup, not a grid, not a presentation. Square corners filled all the way to the edges; iOS will apply its own corner mask. No outside margins, no transparent corners, no outlined icon container, no text labels or app name, no glossy bevel, no glass effects, no metallic/chrome edges, no drop shadows, no busy map details, no airplane, no clock numerals, no watermark. Avoid the thin serif style of the previous brand; use rounded architectural geometry.
```
