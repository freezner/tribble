# SNS 프로필 및 여행 카드 공유 검증

2026-10-29 · 로컬 소스 검증 완료 후 [TestFlight 1.1.1(35)](../1.1.1/TESTFLIGHT-build35.md) 내부 테스트로 업로드·Apple 처리·그룹 연결 완료. 이전 빌드 34 및 정식 App Store 배포에는 포함되지 않음.

## 구현

- 설정에서 Instagram, X, Facebook, TikTok 공개 프로필을 기기에 저장·수정·삭제합니다. 사용자 이름과 공식 프로필 URL 형식을 검사합니다. OAuth 인증이나 실제 계정 소유 확인 기능은 아닙니다.
- 일정 공유 버튼에서 카드 미리보기를 엽니다. 기본값은 프로필 표시 안 함이며 사용자가 표시할 프로필을 선택합니다.
- 피드는 3개 장소씩 1080×1350 PNG, 스토리는 5개 장소씩 1080×1920 PNG로 출력합니다. 긴 경로는 페이지별로 한 장씩 공유합니다.
- 카드마다 전체 일정의 합계, 원래 장소 순서와 도착 시각, 미계산·추정·직접 입력 상태를 유지합니다. 공유를 열 때의 일정 스냅샷을 사용합니다.
- 공유 대상과 실제 게시 계정은 운영체제 공유창 및 선택한 SNS에서 사용자가 확인합니다. 자동 게시나 게시 성공 판정은 하지 않습니다.

## 검증 결과

- `npm test`: 191/191 통과.
- `npm run typecheck`: 통과.
- Xcode 26.2 / iOS 26.2 Simulator / arm64 Debug 네이티브 빌드 성공.
- iPhone 16e: 공개 Instagram URL 입력·정규화·저장 화면을 Expo Go SDK54에서 확인. 새 네이티브 빌드에서 예시 여행을 열어 피드·스토리 전환, 프로필 표시, 페이지 이동, 실제 PNG 캡처와 iOS 공유 시트 전달을 확인.
- 네이티브 PNG의 실제 크기를 헤더로 확인하고 육안 검사함: [피드 1](proof/feed-1.png), [피드 2](proof/feed-2.png), [스토리](proof/story.png). 예시 프로필과 직접 입력 시간을 사용하는 검증용 일정이며 실제 여행/계정 소유를 의미하지 않음.
- 공유 시트 자체 취소 후 버튼이 재활성화되고 임시 PNG가 제거됨을 확인.
- UI 검사에서 발견한 모달의 상태 표시줄 겹침을 SafeAreaProvider로 수정. 빠른 선택 복귀 및 지연된 이전 layout 이벤트의 캡처 준비 상태 덮어쓰기를 회귀 테스트로 방지.
- iOS의 view-shot 포인트/픽셀 배율을 보정하고 2×·3× 및 Android 픽셀 옵션을 테스트함.

## 남은 기기별 확인

실제 Instagram/X/Facebook/TikTok 앱은 시뮬레이터에 없어 해당 앱의 수신·편집·게시 화면과 확장 내부 취소는 검증하지 않았습니다. iOS 공유창 자체의 열기·취소는 검증했으며 실제 게시하지 않았습니다. Android 네이티브 빌드와 iPad 실기기 검증은 이번 작업에 포함하지 않았습니다. 웹에서는 로컬 PNG 공유를 제공하지 않습니다.

후속 배포에서 TestFlight 1.1.1(35)와 한국어 테스트 안내를 반영했습니다. 공개 원격 문서와 정식 스토어 정보는 갱신하지 않았으며 README, 개인정보 안내, 지원 문서는 로컬에서 현재 버전에 맞춰 수정했습니다.
