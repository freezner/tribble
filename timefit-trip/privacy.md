# Tribble 개인정보 및 데이터 처리 안내

최종 갱신: 2026-10-26 · Tribble 1.1.0 기준

Tribble은 하루 여행의 장소, 체류 시간, 이동 시간과 여유 시간을 계획하는 앱입니다. 현재 계정 가입이나 자체 클라우드 동기화 기능은 없습니다.

## 앱 안에 보관하는 정보

여행 이름, 선택한 장소의 이름·주소·좌표·Google 장소 ID, 여행 날짜와 시간, 체류 시간, 교통수단, 이동 계산 결과, 초안, 언어 설정을 기기의 앱 저장소에 보관합니다. 여행은 사용자가 삭제하기 전까지 유지됩니다. 초안은 편집 중 자동으로 보관됩니다.

앱은 이 데이터에 별도의 암호화 계층을 구현하지 않습니다. 기기의 운영체제 보호와 백업 설정이 적용될 수 있으므로, 모든 데이터가 암호화되거나 기기 밖으로 절대 이동하지 않는다고 보장하지 않습니다. 앱 운영자가 접근하는 별도 여행 데이터 서버는 현재 없습니다.

## 장소 검색과 이동 계산

장소를 검색할 때 입력한 검색어와 언어 설정을 Google Maps Platform에 전송합니다. 장소를 선택하면 해당 장소 ID를, 이동 시간을 계산하면 출발·도착 장소 ID 또는 좌표와 교통수단을 전송합니다. 지원되는 교통수단의 계산에는 일정에 설정한 구간 출발 시각도 포함합니다. 네트워크 서비스는 IP 주소 등 통신 정보를 처리할 수 있습니다.

따라서 여행의 로컬 저장과 별개로, 검색 및 경로 계산에 필요한 정보는 Google 서버에서 처리됩니다. Google의 처리 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy)과 [Google Maps Platform 약관](https://cloud.google.com/maps-platform/terms)을 참고해 주세요.

현재 구현은 기기의 GPS나 현재 위치 센서를 읽지 않습니다. 검색하거나 선택한 장소의 좌표와 사용자의 실시간 위치는 구별됩니다.

## 이미지 공유

공유 기능은 현재 여행 정보를 이미지로 만들어 임시 파일로 저장한 뒤 운영체제의 공유 화면을 엽니다. 사용자가 공유 대상 앱을 선택하면 해당 앱에 이미지가 전달됩니다. 공유 이미지에는 여행 이름, 장소, 일정 및 이동 정보가 포함될 수 있으므로 공유 전에 내용을 확인해 주세요.

현재 공유 기능은 사용자의 기존 사진을 읽거나 사진 라이브러리를 탐색하지 않으며, 앨범에 자동 저장하지 않습니다. 공유 대상 서비스의 데이터 처리는 해당 서비스의 정책을 따릅니다. 임시 이미지 파일의 정리는 운영체제와 캡처 라이브러리의 캐시 관리에 따릅니다.

## 삭제와 설정

내 여행에서 개별 여행을 삭제할 수 있고, 설정에서 저장된 여행과 초안을 모두 삭제할 수 있습니다. 언어 설정은 여행 삭제와 별도로 보관됩니다. 이전 저장 형식의 복구용 사본을 보관하는 경우, 명시적인 여행 삭제 시 해당 사본에도 삭제를 반영합니다.

삭제 작업이 실패하면 앱에 오류가 표시됩니다. 앱을 제거하거나 운영체제에서 앱 데이터를 초기화할 때 데이터가 처리되는 방식은 기기의 백업 및 복원 설정에 따라 달라질 수 있습니다.
