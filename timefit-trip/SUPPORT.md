# Tribble 지원

최종 갱신: 2026-10-29 · 현재 개발 소스 기준

> SNS 프로필 등록과 한 장씩 카드 공유는 TestFlight 1.1.1(35)에 포함됐습니다. 전체 카드 일괄 공유·사진 저장 안내·카드 타이틀·출발/설정 도착 시각 구분·저장된 여행 수정 표시와 SNS별 이미지 최적화는 **TestFlight 1.1.1(37)**에서 이용할 수 있습니다. 정식 App Store 버전과는 다를 수 있습니다. [배포 기록](release/1.1.1/TESTFLIGHT-build37.md)을 참고하세요.

> 카드 문구 정리와 일정의 장소별 Google Maps 링크는 **TestFlight 1.1.1(38)**에 포함됐습니다. [빌드 38 배포 기록](release/1.1.1/TESTFLIGHT-build38.md)을 참고하세요.

Tribble은 제한된 시간 안에 여러 장소를 방문할 수 있는지 계획하는 하루 여행 앱입니다. 머무를 시간, 구간별 이동 시간, 이동·대기 여유를 더해 예상 종료 시각과 남거나 초과하는 시간을 보여줍니다.

## 사용 방법

1. **여행 만들기**: ‘내 여행’에서 ‘첫 여행 만들기’ 또는 ‘새 여행’을 누릅니다.
2. **날짜와 시간 정하기**: 일정 화면의 ‘시간 설정’에서 날짜, 시작 시각, 마감 시각과 이동·대기 여유를 입력하고 ‘적용’을 누릅니다.
3. **장소 추가하기**: 장소를 검색해 방문할 순서대로 추가합니다. 출발 장소와 돌아올 장소도 직접 추가해 주세요.
4. **체류 시간과 순서 조정하기**: 각 장소의 체류 시간을 15분 단위로 바꿀 수 있습니다. 출발·귀환 장소는 0분으로 설정할 수 있습니다. 장소의 더보기에서 이름 변경, 순서 이동, 삭제를 할 수 있습니다.
5. **이동 시간 확인하기**: 장소 사이의 이동 구간을 누르면 자동차·도보·대중교통·자전거를 선택할 수 있습니다. 현재 국내 구간은 카카오 API를 중계해 자동 계산합니다. 확인하지 못한 구간은 ‘다시 계산’을 누르거나 보조 기능에서 외부 지도 확인·직접 시간 입력을 선택할 수 있습니다. 한국 구간의 외부 지도는 카카오맵, 그 외 구간은 Google Maps를 엽니다. 지도에서 본 시간을 사용할 때는 교통수단·출발 시각을 확인하고 앱으로 돌아와 분 단위로 직접 입력하세요.
6. **예상 일정 확인하기**: 요약과 타임라인에서 총 소요 시간, 예상 도착·출발 시각, 예상 종료와 여유·초과 시간을 확인합니다.
7. **저장과 다시 열기**: 작성 중 초안은 이 기기에 자동 보관됩니다. ‘저장’으로 여행을 저장하고 ‘내 여행’에서 다시 열 수 있습니다. 저장된 여행은 편집 후 ‘수정’을 누르면 같은 여행에 변경 내용을 저장합니다. 새 여행을 시작해도 이전 초안이 남으며 홈의 ‘이어서 계획하기’ 또는 초안 목록에서 재개합니다. 저장 오류가 있으면 입력 화면에서 재시도해 주세요.
8. **카드 공유하기 — TestFlight 1.1.1(37)**: 일정의 공유 버튼을 누르고 이미지에 맞출 SNS를 선택합니다. Instagram·Facebook은 게시물/스토리도 고를 수 있습니다. 긴 일정은 페이지를 넘겨 미리 볼 수 있고, 공유 버튼을 누르면 모든 페이지의 PNG 이미지를 한 번에 공유창에 전달합니다. 실제 공유 앱은 이 공유창에서 선택하고, 해당 앱에서 게시 계정과 공개 범위를 확인해 주세요. iOS에서는 공유창의 사진 저장 항목을 이용할 수도 있습니다. 여러 장 처리와 저장 항목은 운영체제·대상 앱에 따라 달라집니다.

## 장소를 지도에서 보기 — TestFlight 1.1.1(38)

일정 화면의 각 장소명을 누르면 Google Maps에서 저장된 위치를 확인할 수 있습니다. Google Maps 앱을 사용할 수 없으면 웹 지도가 열립니다. 장소 이름을 수정해도 원래 좌표로 연결되며, 카카오에서 검색한 장소는 좌표 핀으로 표시될 수 있습니다. 공유한 PNG 이미지에는 클릭 링크가 들어가지 않습니다.

## SNS에 맞는 이미지 선택 — TestFlight 1.1.1(37)

SNS 계정이나 프로필을 등록하지 않아도 네 가지 SNS를 모두 선택할 수 있습니다. 이 선택은 이미지의 모양과 크기를 바꾸며 해당 SNS로 자동 게시하거나 공유 앱을 고정하지 않습니다.

| 선택 | 이미지 크기 (가로×세로) | 비율 |
| --- | --- | --- |
| Instagram 게시물 | 1080×1440 | 3:4 |
| Instagram 스토리 | 1080×1920 | 9:16 |
| Facebook 게시물 | 1440×1800 | 4:5 |
| Facebook 스토리 | 1080×1920 | 9:16 |
| X 게시물 | 1200×1200 | 1:1 |
| TikTok 사진 | 1080×1920 | 9:16 |

크기와 여백에 맞춰 한 장에 들어가는 장소 수와 전체 페이지 수가 자동으로 바뀝니다. 모든 장소와 방문 순서는 그대로 유지됩니다. 공유할 때는 현재 미리 보는 장만이 아니라 전체 페이지를 전달합니다. 실제 게시 화면의 잘림이나 재압축은 SNS 앱에 따라 달라질 수 있으므로 게시 전에 확인해 주세요.

X는 한 게시물당 최대 4장, TikTok 사진 게시물은 최대 35장입니다. 이를 넘으면 나누어 게시하라는 안내가 나타납니다. 앱은 전체 페이지 생성을 유지하므로 먼저 모든 이미지를 저장한 뒤 해당 SNS에서 여러 게시물로 나누어 올릴 수 있습니다.

카드에 표시할 SNS 프로필은 출력용 SNS와 별도로 고릅니다. ‘표시 안 함’을 사용해도 이미지 최적화는 적용됩니다. 프로필 표시는 이미지 속 서명이며 게시 계정 인증이나 변경 기능이 아닙니다.

## 카드 타이틀 설정 — TestFlight 1.1.1(37)

설정의 ‘카드 이미지 타이틀’에 표시할 이름이나 닉네임을 입력하고 저장합니다. 앞뒤 공백은 제거되며 입력은 최대 40자로 제한됩니다. 빈값을 저장하면 카드 상단에 기본 이름인 `tribble`이 표시됩니다. 이 이름은 여행 이름이나 SNS 계정을 바꾸지 않습니다. 저장에 실패하면 입력한 이름이 남아 있으므로 다시 시도할 수 있습니다.

카드에는 ‘출발 시각’과 ‘도착 시각(설정)’을 구분해 표시합니다. ‘도착 시각(설정)’은 사용자가 정한 마감 시각이며 실제 경로로 계산한 예상 도착 시각이 아닙니다. 장소별 도착 시간과 전체 여유·초과 안내를 함께 확인해 주세요.

## SNS 프로필 등록 — TestFlight 1.1.1(35) 이상

설정의 SNS 프로필에서 Instagram·X·Facebook·TikTok의 공개 사용자 이름 또는 프로필 주소를 입력하고 저장합니다. 같은 화면에서 수정하거나 등록 정보를 삭제할 수 있습니다. 프로필 옆 열기 버튼으로 공개 주소를 확인할 수 있습니다.

이는 이 기기에 프로필 정보를 등록하는 기능입니다. 계정의 존재나 소유권을 인증하지 않으며 SNS 로그인·OAuth 연결·자동 게시를 하지 않습니다. 비밀번호를 입력하지 마세요. 카드에서 선택한 프로필은 이미지 표시용이므로 공유할 앱이나 그 앱에 로그인된 계정을 바꾸지 않습니다. 프로필을 등록하지 않아도 여행 카드를 공유할 수 있습니다.

## 시간을 읽는 방법

총 소요 시간은 **체류 시간 + 이동 시간 + 이동·대기 여유**입니다. 이동·대기 여유는 계획에 미리 더해 두는 시간이고, 남는 시간은 그 여유까지 포함한 계획과 마감 시각의 차이입니다.

이동 시간은 경로 조회 결과, 추정, 직접 입력을 구분해 표시합니다. 계산 중이거나 확인되지 않은 이동 구간이 있으면 전체 일정의 가능 여부를 확정하지 않습니다. ‘추정’이나 ‘직접 입력’ 표시는 실제 도착을 보장한다는 뜻이 아닙니다.

국내 자동차의 기본 계산은 현재 교통 기준이며 미래 여행의 교통을 예측한 값이 아닙니다. 대중교통도 예정 출발 날짜·시각의 시간표를 확인했다고 보장하지 않습니다. 카드에도 계산 중·미확인·추정·직접 입력 상태를 구분해 표시하므로 실제 이동 전에 교통·운행 상황을 다시 확인해 주세요.

## 자주 묻는 질문

**검색이나 이동 시간 계산이 되지 않아요.**  
인터넷 연결 상태를 확인하고 다시 시도해 주세요. 현재 국내 장소 검색 범위는 대한민국이며 국내 경로는 카카오 중계 API를 사용합니다. 경로 확인 실패는 실제로 이동할 수 없다는 뜻이 아닙니다. 서비스 일시 오류, 요청 한도, 지역·교통수단 지원 범위 때문에 실패할 수 있습니다. 장소를 확인하지 못했다는 안내가 나오면 출발지나 도착지를 다시 검색해 선택해 주세요. 기존 해외 여행의 경로는 Google 호환 조회를 사용합니다.

**한국에서 자동차를 선택했는데 시간이 나오지 않아요.**  
현재 소스는 국내 자동차 시간을 자동 계산합니다. 계산에 실패하면 구간의 ‘다시 계산’을 시도하고, 계속 확인되지 않으면 외부 지도 확인·직접 입력을 사용할 수 있습니다. 지도에서 본 시간은 자동으로 앱에 들어오지 않습니다. 이전 1.1.0 계열 앱에는 국내 자동차 자동 계산이 없으므로 문의 시 설치된 버전을 함께 알려 주세요.

**다시 열었더니 이동 시간을 새로 계산해요.**  
카카오 자동 경로 시간·거리는 여행 저장소에 영구 저장하지 않고 현재 화면의 메모리에서 사용합니다. 앱을 다시 실행해 여행을 열면 저장한 장소·일정으로 다시 조회합니다. 직접 입력한 시간은 보관됩니다. 오래된 자동 계산은 재확인이 필요할 수 있지만 화면을 켜 두었다고 계속 API를 호출하지는 않습니다.

**공유 카드가 방금 계산된 값과 달라요.**  
카드는 공유 미리보기를 열 때의 일정으로 고정됩니다. 이후 경로 응답이나 여행 변경을 반영하려면 미리보기를 닫고 다시 공유해 주세요. 적용하지 않은 시간 설정은 공유를 열기 전에 검사·적용하며, 잘못된 입력은 먼저 고쳐야 합니다.

**SNS 프로필을 등록했는데 다른 계정으로 게시돼요.**  
등록한 프로필은 이미지에 표시할 정보입니다. Tribble이 SNS 로그인 계정을 선택하거나 바꾸지 않습니다. 운영체제 공유창에서 앱을 고른 뒤 해당 앱의 게시 화면에서 계정을 확인해 주세요. 공유창을 닫아도 실제 게시가 끝났다고 확인해 주지는 않습니다.

**공유창에 원하는 SNS가 없거나 이미지를 받지 못해요.**  
표시되는 대상과 여러 이미지의 수신 방식은 기기·설치된 앱에 따라 달라집니다. 대상 앱 상태를 확인하거나 공유창의 다른 저장·전송 대상을 이용해 주세요. 공유창이 열렸다는 것만으로 모든 이미지가 게시됐다고 판단하지 말고 대상 앱에서 장수와 순서를 확인해 주세요. Tribble은 특정 SNS로 직접 게시하는 기능을 제공하지 않으며, 현재 웹에서는 이 이미지 공유를 지원하지 않습니다.

**외부 지도가 열리지 않아요.**  
지도 앱이나 브라우저에서 출발지와 도착지를 직접 검색해 시간을 확인한 뒤 입력할 수 있습니다. 지도에 표시된 교통수단과 출발 시각도 일정과 맞춰 확인해 주세요. 지도에 다녀오는 동안 사용자가 입력 중인 분 값은 자동 경로 응답으로 덮어쓰지 않습니다.

**현재 위치나 돌아오는 구간이 자동으로 추가되나요?**  
현재 위치 센서를 사용하지 않습니다. 출발 장소와 돌아올 장소를 직접 검색해 추가해 주세요.

**다른 기기에서 여행을 볼 수 있나요?**  
현재 계정이나 클라우드 동기화 기능은 없습니다. 여행과 초안은 이 기기에 보관됩니다. 필요한 일정은 이미지로 공유해 따로 보관해 주세요. 앱 삭제나 기기 변경 시 데이터 유지 여부는 기기의 백업·복원 설정에 따라 달라질 수 있습니다.

**저장한 여행을 지우고 싶어요.**  
‘내 여행’에서 개별 여행을 삭제하거나, ‘설정’에서 저장된 여행과 초안을 모두 삭제할 수 있습니다. 삭제 확인 후 진행하며, 실패한 경우 앱에 오류가 표시됩니다. 언어 설정·SNS 프로필·카드 타이틀은 별도로 유지됩니다. SNS 프로필은 해당 편집 화면에서 따로 삭제하고, 카드 타이틀은 입력란을 비운 뒤 저장해 기본값으로 되돌립니다. 이미 공유하거나 사진에 저장한 이미지와 외부 SNS 게시물은 앱의 여행·프로필·타이틀 삭제로 지워지지 않습니다.

**사진 접근 권한이 필요한가요?**
