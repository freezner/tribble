# Tribble 지원

최종 갱신: 2026-10-26 · Tribble 1.1.0 기준

Tribble은 제한된 시간 안에 여러 장소를 방문할 수 있는지 계획하는 하루 여행 앱입니다. 머무를 시간, 구간별 이동 시간, 이동·대기 여유를 더해 예상 종료 시각과 남거나 초과하는 시간을 보여줍니다.

## 사용 방법

1. **여행 만들기**: ‘내 여행’에서 ‘첫 여행 만들기’ 또는 ‘새 여행’을 누릅니다.
2. **날짜와 시간 정하기**: 일정 화면의 ‘시간 설정’에서 날짜, 시작 시각, 마감 시각과 이동·대기 여유를 입력하고 ‘적용’을 누릅니다.
3. **장소 추가하기**: 장소를 검색해 방문할 순서대로 추가합니다. 출발 장소와 돌아올 장소도 직접 추가해 주세요.
4. **체류 시간과 순서 조정하기**: 각 장소의 체류 시간을 15분 단위로 바꿀 수 있습니다. 출발·귀환 장소는 0분으로 설정할 수 있습니다. 장소의 더보기에서 이름 변경, 순서 이동, 삭제를 할 수 있습니다.
5. **이동 시간 확인하기**: 장소 사이의 이동 구간을 누르면 자동차·도보·대중교통·자전거를 선택할 수 있습니다. 경로를 다시 계산하거나, 지도 앱 등에서 확인한 이동 시간을 분 단위로 직접 입력할 수 있습니다.
6. **예상 일정 확인하기**: 요약과 타임라인에서 총 소요 시간, 예상 도착·출발 시각, 예상 종료와 여유·초과 시간을 확인합니다.
7. **저장과 공유**: 작성 중 초안은 이 기기에 자동 보관됩니다. ‘저장’으로 여행을 저장하고 ‘내 여행’에서 다시 열 수 있습니다. 공유 버튼은 일정 이미지를 만든 뒤 기기의 공유 화면을 엽니다.

## 시간을 읽는 방법

총 소요 시간은 **체류 시간 + 이동 시간 + 이동·대기 여유**입니다. 이동·대기 여유는 계획에 미리 더해 두는 시간이고, 남는 시간은 그 여유까지 포함한 계획과 마감 시각의 차이입니다.

이동 시간은 경로 조회 결과, 추정, 직접 입력을 구분해 표시합니다. 계산 중이거나 확인되지 않은 이동 구간이 있으면 전체 일정의 가능 여부를 확정하지 않습니다. ‘추정’이나 ‘직접 입력’ 표시는 실제 도착을 보장한다는 뜻이 아닙니다.

## 자주 묻는 질문

**검색이나 이동 시간 계산이 되지 않아요.**  
인터넷 연결을 확인하고 다시 시도해 주세요. 지역과 교통수단에 따라 경로를 조회하지 못할 수 있습니다. 이동 구간을 눌러 다시 계산하거나, 다른 지도 앱에서 확인한 시간을 직접 입력해 계획을 이어갈 수 있습니다.

**현재 위치나 돌아오는 구간이 자동으로 추가되나요?**  
현재 위치 센서를 사용하지 않습니다. 출발 장소와 돌아올 장소를 직접 검색해 추가해 주세요.

**다른 기기에서 여행을 볼 수 있나요?**  
현재 계정이나 클라우드 동기화 기능은 없습니다. 여행과 초안은 이 기기에 보관됩니다. 필요한 일정은 이미지로 공유해 따로 보관해 주세요. 앱 삭제나 기기 변경 시 데이터 유지 여부는 기기의 백업·복원 설정에 따라 달라질 수 있습니다.

**저장한 여행을 지우고 싶어요.**  
‘내 여행’에서 개별 여행을 삭제하거나, ‘설정’에서 저장된 여행과 초안을 모두 삭제할 수 있습니다. 삭제 확인 후 진행하며, 실패한 경우 앱에 오류가 표시됩니다.

**사진 접근 권한이 필요한가요?**  
공유 기능은 기존 사진을 읽거나 사진 라이브러리를 탐색하지 않습니다. 일정 이미지를 만들어 기기의 공유 화면으로 전달합니다.

## 현재 지원 범위

- 같은 날의 날짜·시작·마감 시각을 기준으로 한 하루 일정
- 장소 검색, 체류 시간·이름·방문 순서 변경
- 구간별 교통수단·이동 시간, 예상 타임라인과 여유·초과 확인
- 기기 내 초안·저장 목록, 일정 이미지 공유
- 한국어·영어·일본어·중국어

자동 경로 최적화, 코스 추천, 여러 날 여행, 실행 중 타이머, 계정 동기화는 제공하지 않습니다. 영업시간·예약·대기열·주차 시간을 자동으로 확인하지 않으며, 이동 시간은 실제 교통·환승 상황에 따라 달라질 수 있습니다.
